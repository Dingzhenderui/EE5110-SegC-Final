# 5分钟英文演示：剪辑和录音执行指南

目标：300秒，16:9，不超过5分钟；主线是完整基线→三个瓶颈→实验发现。报告为英文，口播英文，本文用于中文协作。`NARRATION_EN.md` 是可直接照读的完整讲稿，`narration.srt`采用完整画面检查后的54条显式时间cue，每条至少2.5秒、最多两行。实际录音后仍需微调语音同步，不要赶读。

## 统一画面和声音

- 建议导出1280×720或1920×1080、25 fps。原素材800×600/20 fps，无音轨，不能拉伸成16:9；置于画面左侧，右侧放研究问题/关键数字，底部留两行字幕。
- 所有2倍播放明确写 `2x simulation playback`。短片尾部补足不足1.1秒的静帧应写 `freeze frame`，不能让观众误认实时动作停顿。
- 仿真动作旁标记 `Illustrative development run`；正式结果旁标记 `Frozen paired evaluation`。截图中的force/strain曲线为单个开发演示，不是组平均。
- 口播约600–700词、125–140词/分；先按各章节时长录音再微调。保留短停顿，背景音乐非必要。自动生成的字幕版预览**没有口播**，需录音后替换音轨。
- 第一镜头展示机械臂和任务，标题不要超过7秒；结束展示结论、复现入口和源代码，而不是仅写Thank you。

## 关键镜头核对

1. **基线对象展示**：`02_random_YCB_objects.mp4` 是逐个模型与随机位姿的展示，不能声称镜头拍到了随机选择算法本身。真正随机执行素材为 `05_randomized_trials.mp4`，如果替换应先看每次边界并保留失败，不把六次开发试验当正式大样本。
2. **候选对比**：`03_comparisons/01_rejected_grasps.mp4` 3.95秒原速，计划延长为5秒（最后1.05秒静帧）；随后同场景48.3秒改进片以2倍速播放24.15秒，加0.85秒静帧。root_seed均为20261608。不要剪成“机械臂尝试撞上物体之后重试”，因为旧候选根本未执行。
3. **软体**：YCB foam_brick原来是刚体，必须用 `02_deformable.mp4` 展示真正flex。均值应变3.67%→4.90%，不能写“更温柔/更小变形”。
4. **感知**：机器人动作本身看不出滤波机制，必须保留点云图与三个结果数字。跨不同包至少3次支持不意味着包在统计上独立；AR漂移依旧相关。
5. **恢复**：`06_failure_recovery.mp4` 60.9秒整段以2倍速播放，保留第一次失败、张开撤离、再观测/抓取和释放，并在190–193.5、193.5–196、196–201秒分别加失败、撤离、重抓标签，不要拼接不同场景。首次fault是真正命令58mm开口，目标40mm；不是自然故障统计。
6. **铰接/未知形状**：铰接是被动关节整件搬运，不是主动开盖；未知形状是未见的程序生成实例，不是神经网络零样本学习。

4名口播者可按00:00–01:10、01:10–02:25、02:25–03:40、03:40–05:00分配；5人可把结果/结束独立成一段。口播分工只代表录音分工，不能作为研发贡献声明。实际组员姓名、学号和工作内容由小组如实填写。

## 录音后导出

先录出一条约300秒的WAV或M4A（章节间可留停顿），在剪辑软件中沿`shot_list.csv`放置素材并导入`narration.srt`。如果直接使用字幕预览MP4，加一条独立口播轨后导出即可。用ffmpeg合成时示例：

```powershell
ffmpeg -i deliverables/EE5110_5min_reviewed_preview.mp4 -i narration.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -af apad -t 300 -movflags +faststart deliverables/EE5110_Final_Demo.mp4
```

这里`narration.wav`必须由实际录音提供，不能把没有录音的预览说成已配音。上面的`-t 300`只控制成片长度，不能用来截断超时讲稿；录音应先对齐300秒。字幕时间已按画面修订，录音后仍须检查逐句语音同步。

## 提交前检查

- 报告最多10页，团队身份如课程需要已填写；讲稿及成片不需要额外的工具使用说明。
- 视频包含介绍、完整真实抓放、算法机制、数据和局限；字幕不挡夹爪/目标。
- 2x/静帧标识明确，开发演示和正式实验分开。
- 提交ZIP应使用`--version 3.1.0`，`--video`指向最终配音成片；没有配音时不会把预览自动冒充最终视频。
- 包内应有唯一主报告、演示视频、源代码、主函数/实验运行说明、LaTeX源码和证据；不要直接提交旧v3.0历史ZIP。
